# Private test build

This is a separate test build, not a live recruitment system. Open index.html and choose a location. Nairobi contains two simulated openings: cashier and shelf attendant. Additional fictional openings are spread across other towns; each role has at most one. All staffing counts, vacancy counts and salaries are fictional illustrative figures, not information from Naivas. These are not real branch headcounts and do not establish that a branch or role exists at a particular location.

Use fictional personal details only. The test submission simulates a loading screen and confirmation entirely in memory; no application, CV, email, ID or PIN is transmitted or saved. No employer is notified. It does not test an actual backend, email, WhatsApp, data retention or production security. Use the original non-test ZIP for production integration. Never publish this test build as actual vacancies.

Salary estimates are indicative monthly amounts for testing, not verified Naivas compensation or binding job offers. Working assumptions use Kenya job market sources and the 2026 corrected general wages schedule, where applicable. Monthly wage figures can refer to basic wages or net pay; these sources are not directly equivalent and salary/allowance obligations require separate verification. Sample market references:
